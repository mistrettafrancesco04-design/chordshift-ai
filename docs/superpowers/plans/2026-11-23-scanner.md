# Dokumentenscanner Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Statische iPhone-Web-App (PWA) in `scanner/`, die per Live-Kamera Blätter erkennt, entzerrt, aufbereitet und als mehrseitiges PDF teilt.

**Architecture:** Kein Build-Schritt, reine ES-Module. Reine Geometrie-/Seitenlogik in `geometry.js` (in Node getestet); OpenCV-abhängige Teile (`detect.js`, `enhance.js`) werden im Browser per Playwright mit synthetischen Bildern getestet. UI in `app.js` steuert drei Bildschirme (Kamera, Seite prüfen, Seiten & PDF); Seiten liegen in IndexedDB.

**Tech Stack:** Vanilla JS (ES-Module), OpenCV.js (`@techstark/opencv-js@4.12.0-release.1`, Datei `dist/opencv.js`), jsPDF (`jspdf@4.2.1`, `dist/jspdf.umd.min.js`), Service Worker, `node:test`, Playwright (vorinstalliert).

**Spec:** `docs/superpowers/specs/2026-11-23-scanner-design.md`

## Global Constraints

- Alles läuft auf dem Gerät; keine Netzwerkanfragen außer zum eigenen Origin.
- Bibliotheken liegen unter `scanner/vendor/`, nicht per CDN zur Laufzeit; Service Worker cacht alles (offline).
- UI-Texte auf Deutsch.
- Fertige Seite: lange Seite max. 2480 px.
- Seitengröße: Verhältnis innerhalb ±10 % von A4 (1:√2) → A4 210×297 mm (quer: 297×210); sonst Breite 210 mm (bzw. Höhe 210 mm bei Querformat) und echtes Verhältnis.
- Dateiname Standard `Scan_JJJJ-MM-TT_HH-MM.pdf`.
- Filter: `auto` (Standard, Farbe bleibt), `bw`, `gray`, `original`.
- Auto-Auslösen nach ca. 1 s stabiler Ecken; abschaltbar.
- Kamera: Rückkamera, `width: {ideal: 3840}, height: {ideal: 2160}`.
- Safe-Area beachten (`env(safe-area-inset-*)`), dunkle Oberfläche, erkannte Fläche halbtransparent blau.

## Review Focus

1. **Kein Blatt im Bild / Blatt angeschnitten** → keine Umrandung, kein Auto-Auslösen; manueller Auslöser nimmt das ganze Bild mit Ecken = Bildecken (Task 3/6).
2. **Kassenbon (sehr schmal, z. B. 1:4)** → keine A4-Verzerrung, PDF-Seite 210 mm × echtes Verhältnis (Task 1).
3. **Kamera verweigert / nicht verfügbar / HTTP statt HTTPS** → klarer deutscher Hinweis und Galerie-Import bleibt nutzbar (Task 6).
4. **App-Wechsel oder Neuladen mitten im Scannen** → bereits aufgenommene Seiten sind wieder da (Task 5).
5. **Ecken vom Nutzer überkreuz gezogen** → Ecken werden neu sortiert, keine gespiegelte Seite (Task 1, `orderCorners`).

## Dateistruktur

```
scanner/
  index.html              App-Gerüst, drei <section>-Bildschirme, Meta-Tags für iOS
  styles.css              Optik
  manifest.webmanifest    PWA
  sw.js                   Cache-first Service Worker
  icons/icon-180.png, icon-512.png
  vendor/opencv.js, vendor/jspdf.umd.min.js
  js/geometry.js          reine Logik (keine DOM/OpenCV-Abhängigkeit)
  js/cv.js                OpenCV laden: loadCv(): Promise<cv>
  js/detect.js            detectQuad(cv, imageData) → Quad | null
  js/enhance.js           warpQuad(...), applyFilter(...)
  js/camera.js            Kamera-Stream, Einzelbild, Taschenlampe
  js/store.js             IndexedDB-Seitenablage
  js/pdf.js               buildPdf(pages, title) → Blob
  js/app.js               UI-Steuerung
package.json              devDependencies + Skripte (Repo-Wurzel)
tests/unit/geometry.test.mjs
tests/e2e/*.spec.mjs      Playwright-Tests (eigener kleiner Runner, s. Task 3)
tests/fixtures/make-fixtures.mjs  erzeugt synthetische Testbilder
```

Typen (JSDoc): `Point = {x:number, y:number}`; `Quad = [Point,Point,Point,Point]` in Reihenfolge oben-links, oben-rechts, unten-rechts, unten-links.
`Page = { id:string, original:Blob, quad:Quad, rotation:0|90|180|270, filter:'auto'|'bw'|'gray'|'original', processed:Blob, width:number, height:number, createdAt:number }`.

### Task 1: Projektgerüst + Geometrie

**Files:** Create `package.json`, `scanner/js/geometry.js`, `tests/unit/geometry.test.mjs`, `.gitignore` (`node_modules/`)

**Interfaces – Produces (`geometry.js`):**
- `orderCorners(points: Point[4]) → Quad`
- `quadArea(q: Quad) → number`, `isConvex(q: Quad) → boolean`
- `outputSize(q: Quad, maxLong=2480) → {width, height}` – Breite = max(obere, untere Kante), Höhe = max(linke, rechte), skaliert, sodass lange Seite ≤ maxLong.
- `pageSizeMm(width, height) → {w, h}` – Regel aus Global Constraints.
- `smoothQuad(prev: Quad|null, next: Quad, alpha=0.5) → Quad`

- `scaleQuad(q, sx, sy) → Quad`, `fullFrameQuad(w, h) → Quad`, `defaultFileName(date: Date) → string`
